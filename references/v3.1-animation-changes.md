# V3.1 · animation and timing changes (for developers)

Diff: `references/v3.1-shortened-animations.diff` (unified, no context lines; base = V3.1 as uploaded).
Line 4-5 and the last lines of the diff are only the artifact wrapper, ignore them.
"Scene seconds" are the numbers in `SCENES`; real seconds = scene seconds x `PROC_SLOW` (now 0.8).
Timings were measured in a slow headless sandbox, so treat them as relative.

## Success checkmark gap
- `hyDoc`: the idle wait before each loader's success tick is kept at 35% (`END - ... ) * .35`).
- New `message` listener: when a step's loader posts `done`, the step ends 0.6 s later instead of waiting for the end of its time slot.

## Scanning verified sources
- `SCAN_T0` .8 -> 0 and `SCAN_PER` 2.6 -> 2.1 (each source takes 2.1 scene seconds, scan starts at once).
- `scanTick`: no slide-in. `pre=0`, first card (k=0) is already centred (`c=0`, `mv=.03`); later cards still glide (`mv=.3`).
- `scanIntro` (now unused because the intro has `dur:0`): fade `(lt-.1-i*.09)/.8`, blob wake `lt/.8`.

## Template remap / recalc screen (`recalc`)
- Shows a 3-line typed list (`rcThinkStart`, 1.7 s per line, ticks as the next starts) instead of one line. Brands recalculation has its own 3 lines.
- Templates remap now plays 10 s then continues (`later(...,10000)`); brands recalculation unchanged (4.8 s).
- "This process may take some time" note: no amber, no box, smaller and softer, placed below the animation (`.rcbox`, positioned in `hyFit`).
- "Step X of Y" pill on animation cards hidden (`.hyCard-lab{display:none}`).
- New Prototype state "Mapping templates to brands and LOBs" (`tpl-mapping`).

## Other behaviour changes in this version (not animations)
- KYC approval check: the headline stays "Sending your KYC details to the telecom operators"; "Waiting for their approval" is the line under it (`kvText`).
- "Up next" bar: countdown 8 -> 5 s, new "Stay on this page" button.
- Save dialogs: "Keep editing" removed, X added top right.
